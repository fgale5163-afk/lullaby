# Lullaby

A lightweight Spotify player for Windows with a macOS glass look. It uses about a quarter of the memory of the Spotify app, has a Spotify-style Autoplay, a queue, and Jams to listen with friends.

## Download

**[Download Lullaby.zip](https://github.com/fgale5163-afk/lullaby/releases/latest/download/Lullaby.zip)** (always the newest version)

You need Windows 10 or 11 and Spotify Premium.

1. Extract the zip to a folder you'll keep (for example `Documents\Lullaby`).
2. Open `Lullaby.exe`. If Windows says "Windows protected your PC", click **More info → Run anyway**.
3. Follow the steps Lullaby shows to connect it to Spotify (about 2 minutes, one time).

The full guide is in `How to set up Lullaby.txt` inside the zip. Lullaby updates itself after that.
